# Capstone-Project-Solar

### Data Sources

- The CSV files containing electricity production and storage installation data were downloaded from [data.gouv.fr](https://www.data.gouv.fr/datasets/registre-national-des-installations-de-production-et-de-stockage-delectricite-au-31-08-2026).
- To find data for previous years, I searched for **"Registre national des installations de production et de stockage d'électricité (au 31/08/20XX)"**, replacing `XX` with the last two digits of the desired year.
- The downloaded CSV files are used for the analysis in this project.
